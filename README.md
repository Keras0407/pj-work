## Download the zip (343 MB)

**Direct file:** https://github.com/Keras0407/pj-work/releases/download/v1.0.0/pj-work.zip

**Release page:** https://github.com/Keras0407/pj-work/releases/tag/v1.0.0

- `docker-images/librenms-images.tar` — LibreNMS, MariaDB 10, Redis 7.2, msmtpd
